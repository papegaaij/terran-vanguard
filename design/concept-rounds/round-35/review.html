Concept round 35: record of the decisions

The review round of M6 Acts 1–2 release (roadmap): part A mouse support, part B the high scores and the release's end, part C the release plumbing and part D the polish and close-out, built while the user was on vacation. Every default, pick and build choice below was taken on the user's behalf (the gap check's recommendation) and is pending the user's review; three of them were flagged risky (Q1 the end card's text, Q3 the main-menu change, Q5 Okafor's new line). It can be answered in the same sitting as round 34.

Open index.html in a browser (regenerate with python3 tools/concept/board.py 35 --subjects pointer,app-icon,m6-capture: round 34 already used the r35 file names for Level 13, so the board keeps only this round's three subjects). The questions keep their numbers from the M6 gap check (Q1–Q15); the build's own choices are numbered per part (A.1, B.1, …), each answered yes (keep as built) or no (say what to change). Read the two boxes first: what changed in approved specs, and the two questions only the user can answer.

In the game

./gradlew :desktop:run --args="…" with --settings <file> to keep the real settings apart. A debug run never writes a save or a score (the screens say so):

  • the mouse, the SCORES screen and the hangar: no arguments, then New game;
  • the hard game over with Okafor's line: --difficulty hard --level 8 and lose four times;
  • the release's end: --level 14 --invulnerable --loadout front=lance-laser:5,left=micro-missile-pod:5,right=micro-missile-pod:5, kill the Spire, then confirm through the debrief, the act summary and the outro. A played campaign (from a save after Level 13) shows the end card without the debug line and enters the score.

release-notes.md

# Terran Vanguard @tag@ — Acts 1 and 2

A late-90s style vertical shoot'em up set in 2185. This release holds the first two of the campaign's seven acts: fourteen levels on easy, medium or hard, with their briefings, radio chatter, shop and hangar, the Act 1 and Act 2 bosses and the act outros. The later acts follow in later releases.

## Download

SystemFile
Windows 10/11, 64-bitterran-vanguard-@version@-winX64.zip
macOS, Apple Silicon (M1 and later)terran-vanguard-@version@-macM1.zip
macOS, Intelterran-vanguard-@version@-macX64.zip
Linux, 64-bit x86terran-vanguard-@version@-linuxX64.zip

Unpack the zip anywhere and start the game from the terran-vanguard-@version@ folder; it brings its own Java runtime, nothing has to be installed. README.txt in that folder has the controls and where the settings, saves and screenshots are kept.

## The game is not signed

  • Windows: SmartScreen may say "Windows protected your PC". Choose More info, then Run anyway (only on the first start).
  • macOS: the first start is refused ("cannot be opened because the developer cannot be verified"). Control-click the app, choose Open and confirm, or choose Open Anyway in System Settings → Privacy & Security. If macOS says the app is damaged, run once in Terminal: xattr -dr com.apple.quarantine "/path/to/Terran Vanguard.app".
  • Linux: if the game does not start, make it executable: chmod +x terran-vanguard.

## Requirements

A 64-bit system with OpenGL 3.2 or newer (any graphics chip from the last ten years); keyboard or gamepad. The game starts in borderless full screen; Alt+Enter or F11 switch to a window.

## Licence and credits

The game is open source under the Apache License 2.0 (LICENSE.txt). CREDITS.md lists every third-party file (sound effects, fonts) with its author and licence.

Weak spots (Claude) "keyboard or gamepad" under Requirements does not mention the mouse in the menus

Per-level bench (M6 part D)

Measured 2026-10-12 on the development machine (20 threads, 62 GiB) without a GPU: Xvfb with Mesa's llvmpipe software renderer, so every frame is rasterised on the CPU, the nearest thing at hand to modest graphics hardware. Each of Levels 01–14 ran once from the :desktop:installDist build: --bench <s> --level <n> --invulnerable --debug-speed 1 at medium, a 1920×1080 window (pixel scale 2), auto-fire on, the ship left at its start (nothing dodged, every attack's bullets on screen), Rook flying from Level 08, OpenAL Soft's wave driver, -Xmx1g (a modest machine's heap; the default is a quarter of the RAM) with -Xlog:gc,safepoint, the peak resident set from /usr/bin/time -v. The run is the level's last section end plus 15 s, so it covers the level and, where the boss is not killed, its fight; nothing was done between runs.
