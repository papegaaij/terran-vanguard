# Concept round 47 — five sounds redone from real recordings

## Summary

Five of round 46's sounds were answered "redo". Each subject below says where and when it plays and what it should sound
like, then two new variants **a** and **b**, described by how they sound, next to the **old** file the game plays now.
The proposals are cut from Freesound's free previews (CC0 or CC-BY, credits in [CREDITS.md](../../../CREDITS.md)); the
one you pick is rebuilt from the full-quality original afterwards with the same settings. Answer per row: a, b, or redo
(say why). Nothing is in `assets/` yet.
