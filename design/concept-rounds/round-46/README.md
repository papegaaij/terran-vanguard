# Concept round 46 — Freesound sounds for the synthesized ones, the GitHub README draft

## Summary

Your rule of 2026-10-20: **ask only about artwork, sounds, boss fights and important game concepts.** This round holds
two things:

1. **Sounds** (`J` and `K` rows, 42 subjects). You said the synthesized sounds are horrible for "explosions, fire,
   turrets, hits, etc. Everything that needs to sound somewhat accurate", and that the Ghost Drone sounds are "pling plong
   on a xylophone". Each subject has two variants **a** and **b** built from Freesound recordings (CC0 or CC-BY only,
   credits in [CREDITS.md](../../../CREDITS.md)), playable next to the **old** file the game uses now. Answer per row:
   a, b, or redo (say why). Nothing is in `assets/` yet; the picks move there when you answer. Where one variant is
   clearly better I say so; otherwise I have no recommendation, because I cannot listen. The Freesound daily download
   quota ran out during the work, so a redo can start tomorrow at the earliest.
2. **The GitHub README** (`R` rows): you found the start of the README not very inviting. A draft with a hero GIF, eight
   screenshots and a feature list, to use as drafted or change. **No GitHub release exists yet**, so the draft's
   Download link points to an empty page until the first `v*` tag.

Pickups, UI sounds, pings, jingles and music were not touched.
